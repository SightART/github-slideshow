# ModuLuxe Commerce Theme

## Installatie
1. Kopieer de map `moduluxe` naar `wp-content/themes/`.
2. Activeer het theme in WordPress.
3. Installeer en activeer WooCommerce.
4. Stel menu's in voor `Primary` en `Footer`.
5. Maak een statische homepage en wijs deze toe aan `Front page`.

## Uitbreiding
- Voeg ACF velden toe voor USP's en adviesblokken.
- Gebruik object cache + page cache voor extra performance.
- Voeg product schema via SEO-plugin toe.
